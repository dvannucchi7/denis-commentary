=== LEFT ===
⟦Is. lxiv, 1.⟧ vit Isaias, dicens : _Utinam dirumperes cœlos, et descenderes._ Unde per cœlos intelligi possunt cœli materiales, præsertim cœlum empyreum : quos dicitur Deus inclinare sive dirumpere, non localiter neque realiter, sed per similitudinem quamdam. Loquitur enim Scriptura de Deo modo humano. Homo autem, in loco sublimi nullam aperturam habens exsistens, non valet descendere, nisi locus inclinetur aut dirumpatur. Idcirco rogatur Deus cœlos inclinare atque dirumpere. Vel sic : _Domine, inclina cœlos tuos,_ id est, angelos sanctos, civesque cœlestes, depone et mitte ad nos, _et descende,_ id est, gratiam et misericordiam infundendo veni ad me. Utroque modo Christus descendit. Carnem enim assumpsit, et misericordiæ suæ effectum nobis impendit.

_Tange montes,_ id est superbos, se ipsos inaniter erigentes per vindictam ; _et fumigabunt,_ id est dissolventur et corrumpentur, quemadmodum candela dum extincta fuerit, fumigat. Vel, _Tange montes_ istos per misericordissimam gratiæ infusionem, _et fumigabunt,_ id est, lacrimas pro suis excessibus fundent, gement, et ad ⟦6⟧ cœlestia suspirabunt. (7) _Fulgura coruscationes,_ id est, terribiles exerce ultiones ; _et dissipabis eos,_ id est, superbos confringes et condemnabis. Vel : _Fulgura,_ id est, evidenter emitte, _coruscationes,_ id est miracula et verba sanctæ prædicationis ignita ac splendida ; _et dissipabis eos,_ id est, superbos a sua elatione disperge, convertes et immutabis, faciendo humiles de elatis, parvos de magnis. _Emitte sagittas tuas,_ id est comminationes horribiles, commemorando per sanctos prædicatores districtionem futuri judicii ac pœnas inferni ; vel, _Sagittas,_ id est pœnas castigatorias ; _et conturbabis,_ id est terrebis, eos ad pœnitentiam salutarem. Talia namque audiendo impii convertuntur.

_et fumigabunt,_ id est deficient, prout de impiis ab Isaia dicitur : _Radix eorum quasi favilla erit, et germen eorum ut pulvis ascendet._ ⟦Is. v, 24.⟧ Nam et Philistæi, occiso suo gigante, fugerunt. ⟦I Reg. xvii, 51.⟧

Deinde vir justus divinum auxilium postulans, subdit : (8) _Emitte manum tuam de alto,_ id est, de cœlo mitte mihi subsidium, tamque potestatem extende super me ; _eripe me et libera me de aquis multis,_ id est ab hominibus malis, a tribulationibus variis, a dæmonum tentamentis. Per aquas enim interdum populi designantur, juxta illud : _Aquæ quas vidisti, populi sunt._ ⟦Apoc. xvii, 15.⟧ Interdum vero per aquam tribulatio importatur, sicut quum a Jeremia dicitur : _Inundaverunt aquæ super caput meum._ ⟦Thren. iii, 54.⟧ _Et de manu filiorum alienorum,_ id est hominum perversorum ac dæmonum : qui per naturam sunt filii Creatoris, tanquam ad ejus similitudinem conditi ; per inobedientiam autem sunt filii iniquitatis : sunt-que alieni a Deo, et nesciuntur ab eo. (9) _Quorum os locutum est vanitatem,_ id est vana consilia, verba iniqua, _et dextera,_ id est potestas eorum, est dextera iniquitatis, id est origo et causa peccati. Potestate enim sibi divinitus præstita abutuntur, exhibentes vires seu membra sua ⟦Rom. vi, 19.⟧ servire immunditiæ et iniquitati ad iniquitatem, sicut Apostolus dicit.

Quoniam vero de his malis misericorditer eripuisti me, Domine, ideo, o (10) _Deus, canticum novum,_ id est laudem recentem, ex recenti devotione prodeuntem, _cantabo tibi,_ gratias referendo ; _in psalterio decachordo,_ id est decem chordas habente, videlicet in spirituali psalterio, quod est observatio præceptorum Decalogi, _psallam tibi :_ id est, laudabo te, non solum pulchris sermonibus, sed etiam sanctis operibus, ne inter eos computer de quibus testatus es : _Populus iste labiis suis glorificat me, cor autem ejus longe est a me._ ⟦Is. xxix, 13; Matth. xv, 8.⟧ (11) _Qui das salutem regibus,_ id est victoriam principibus. Unde Salomon loquitur : _Equus paratur ad prælium; Dominus autem salutem tribuit._ ⟦Prov. xxi, 31.⟧ Et iterum Sapiens
