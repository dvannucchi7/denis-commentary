_Hæc,_ id est Ecclesia seu anima munda, ⟦14⟧
devota et studiosa, _requies mea in sæculum sæculi :_ sicut dixi, _Ecce ego vobiscum sum_ ⟦Matth. xxviii, 20.⟧ cunctis diebus. Dicitur autem Deus immobilem requiem habere in nobis, non quod
ipse unquam turbetur aut moveatur, sed
quoniam facit corda nostra in ipso quiescere. _Hic habitabo_ per gratiam, _quoniam elegi eam_ mea bonitate, non ejus virtute. _Viduam ejus,_ scilicet Ecclesiæ, id est feminam viri solatio destitutam, et de cetero propter me continentem, nec in deliciis viventem, _benedicens benedicam,_ dando ei necessaria vitæ, gratiamque in præsenti, et gloriam in futuro. Unde de talibus viduis scribens Apostolus : Viduas, inquit, ⟦1 Tim. v, 3.⟧ honora, quæ vere viduæ sunt. Vel : Viduam, id est animam fidelem humano solatio destitutam, et vana gaudia contemnentem, benedicens benedicam. _Pauperes ejus,_ id est egenos Ecclesiæ, scilicet pauperes spiritu, quorum est regnum cœlorum, _saturabo panibus_ vitæ et intellectus, ⟦Matth. v,3.⟧ ⟦Eccli. xv,3.⟧ pane sacramentali, pane lacrimarum, pane ⟦Ps. lxxxix,6.⟧ operum bonorum.

_Illic,_ id est in Ecclesia, _producam,_ id est, formabo, conservabo et prolongabo, _cornu David,_ id est dignitatem atque potentiam Christi, dando Ecclesiæ magnam dignitatem ac potestatem in nomine Christi. Vel : _Illic,_ id est in futuro judicio atque in patria, _producam,_ id est, proferam et ostendam, _cornu David,_ id est regiam seu judiciariam potestatem Christi, quæ illic præcipue apparebit, ubi videbitur in majestate gloriæ suæ. _Paravi lucernam,_ id est claram ac sempiternam memoriam, _Christo meo :_ quoniam nomen Christi ubique gloriosum et notum est. Vel, Lucernam, id est vasa gratiæ, scilicet homines bonos, in quibus Christus per gratiam splendet, quemadmodum in lucerna lucet candela.
