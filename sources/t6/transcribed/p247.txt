=== LEFT ===
⟦v. 9⟧ _De cœlo auditum fecisti judicium :_
id est, justam ultionem, quam exercuisti
in omnem exercitum Assyriorum, audiri
fecisti in terra de cœlo, id est virtute cœ-
lesti, qua hanc ultionem fecisti. Sicut enim
hæc ultio de cœlo facta est ministerio an-
geli, sic dicitur audita de cœlo, quoniam
virtus cœlestis, quæ fuit causa exsistentiæ
hujus ultionis, exstitit etiam causa pro-
mulgationis ipsius. Vel sic : De cœlo au-
ditum fecisti judicium, id est, audiri fe-
cisti ab hominibus judicium cœleste : sic
quoque quod dicitur, De cœlo judicium,
tantum est dicere, ac si dicatur, Judicium
cœleste. Hoc autem cœleste judicium fuit,
quod Dominus de rege atque exercitu As-
syriorum peregit, occidendo tantam cater-
vam. Vel sic : De cœlo auditum fecisti ju-
dicium, id est, cœlitus revelasti judicium
istud. Revelavit enim Deus Isaiæ, quæ fu-
tura erant regi huic et populo ejus ; imo
Isaias frequenter in libro visionum suarum
⟦Is. xxxvii, 21-35.⟧ inde vaticinatur. Isaias quoque id ipsum
Ezechiæ prædixit. _Terra tremuit,_ id est,
populus Judæorum propter adventum As-
syriorum vehementer expavit. Vel dicitur
terra tremuisse, propter multitudinem ex-
ercitus Assyriorum : quemadmodum primo
⟦I Mach.ix, 13.⟧ Machabæorum habetur,Commota est terra a
voce exercituum. _Et quievit,_ id est, populus
terræ Judææ a suo pavore cessavit, occisis
⟦v. 10⟧ Assyriis. ⟦v. 9⟧ _Quum excurgeret in judicium_
_Deus,_ id est, in actum judicandi procede-
ret, committendo angelo suo, ut prædictum
populum trucidaret, _ut salvos faceret om-
nes mansuetos terræ,_ id est, quatenus Eze-
chiam regem mitem et sanctum cum po-
pulo suo de manu Assyriorum erueret.
