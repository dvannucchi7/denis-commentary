(10) _In matutino,_ id est tam cito ut commode justeque potui, _interficiebam gladio materiali vel spirituali omnes peccatores_ ⟦8⟧ _terræ,_ hoc est omnes graviter criminosos, causas morte dignas habentes, _ut disperderem de civitate Domini,_ id est de Ecclesia seu congregatione justorum, _omnes operantes iniquitatem_ tam gravem, ut dictum est. Debent namque principes sæculares gladio materiali, prælati autem gladio spirituali, iniquos occidere, seu intus mortuos declarare, ut mundent Ecclesiam a commixtione pravorum, secundum Decreta. — Vel : _In matutino,_ id est in exordio ⟦24, q.1. Augustinus.⟧ tentationis, _interficiebam,_ id est, cadere atque deficere feci, per orationem devotam et adjutorium gratiæ Christi, _omnes peccatores terræ,_ id est diabolos me tentantes, et terrenas concupiscentias mihi suggerentes ; _ut disperderem de civitate Domini,_ id est de consensu animæ meæ, quæ est civitas Dei, _omnes operantes iniquitatem,_ id est omnia diabolica tentamenta, me ad opera mala inducere quærentia.
