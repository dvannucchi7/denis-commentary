⟦17⟧ _Hi sunt fontes sine aqua,_ id est doctores ficti carentes vera doctrina : quia doetores se esse præsumunt et jactant, quum
deceptores existant, sicque assimilantur
fonti siccato; _et nebulæ turbinibus exagitatæ,_ id est similes nebulis a ventis hinc
inde commotis : quoniam dæmonum suggestionibus et vitiorum impulsibus circumferuntur ; _quibus caligo tenebrarum reservatur :_ quia ut ait Salvator, projicientur in tenebras exteriores, ut de tenebris vitiorum præcipitentur in tenebras
tormentorum. Et recte obscuritas infernalis caligo tenebrarum, quasi caligo caliginum, appellatur, quum sit vehementissima, quemadmodum rosa flos florum
vocatur.
⟦18⟧ _Superba enim vanitatis loquentes,_ id est verba falsitatis pomposa; vel, ut alii legunt, Superbia vanitatis, id est ex arrogantia propriæ vanitatis, loquentes : _pelliciunt in desideriis carnis luxuriæ,_ id est, per concessionem et approbationem concupiscentiarum carnalium fallunt, _eos qui paululum effugiunt,_ id est imperfectos, qui aliqualiter se ab erroribus ac peccatis cœperunt abstrahere; _qui deceptores in errore conversati,_ id est assuefacti, ⟦19⟧ _libertatem illis promittunt,_ id est, deceptis a se affirmant quod libere sine peccato possint carnalia desideria adimplere.
