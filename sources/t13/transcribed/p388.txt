_Propter quæ vitia venit ira Dei_, id est divinæ justitiæ ultio, _super filios incredulitatis_, id est in homines infideles ac
⟦7⟧ reprobos ; _in quibus peccatis et vos_, Colossenses, _ambulastis_, id est conversati estis, _aliquando_, eundo de malo in pejus, _quum viveretis in illis_, quando videlicet nondum conversi fuistis ad Christum.

_Nunc autem deponite et vos omnia_ quæ sequuntur, videlicet : iram, quæ inordinatus appetitus est vindictæ propter parvipensionem, indignationem, quæ ex superbia et ira procedit, malitiam, id est machinationem mali in alium corde conceptam, blasphemiam contra Deum et Sanctos, turpem, id est impudicum, sermonem deponite de ore vestro. _Nolite mentiri invicem._ Os enim quod mentitur, occidit ⟦Sap. i, 11.⟧ animam, ut dicitur in libro Sapientiæ.

_Exspoliantes vos_, id est exuentes, _veterem hominem_, id est pristinum statum, vel vosmetipsos quoad id quod fuistis per culpam, _cum actibus suis_ vitiosis ; _et induentes novum_, id est, per opera bona ac sacramenta et gratiam, induite hominem spiritualiter reformatum, id est, vos ipsos innovate interius, _qui novus homo renovatur et crescit quotidie in agnitionem Dei_, id est contemplando divina. Renovatur autem hoc modo : _secundum imaginem ejus_, id est quantum ad partem intellectivam, in qua est imago ejus _qui fecit eum_, id est summi Creatoris, cujus imago resplendet in superiori parte animæ rationalis : quæ pars potestativa renovatur quotidie recipiendo a Deo gratiæ incrementa, ornamenta virtutum et sapientiæ claritatem ; _ubi_, id est in quo homine interiori ac novo, videlicet in parte animæ intellectiva, _non est masculus neque_
