⟦v. 24⟧ patria. _Et consideremus invicem,_ id est,
nos mutuo adspiciamus, pensando quid
singuli quique habeant dignum imitatione
vel increpatione, _in provocationem caritatis et bonorum operum,_ id est ad hunc
finem ut in caritate Dei ac proximi accendamur, atque in bonis operibus excitemur, dum quisque bonum alterius imitatur, ejusque defectum caritative redarguit: quæ omnia sunt caritatis effectus, eamque accendunt. Non tamen esse debemus curiosi scrutatores vel observatores aliorum, sed moderate, prout caritas postulat, unusquisque alium admonere debet sive corripere.
⟦v. 25⟧ ripere. _Non deserentes collectionem nostram,_ id est congregationem fratrum seu cœtum fidelium, inter quos habitamus; _sicut est consuetudinis quibusdam,_ qui tempore persecutionis, vel ex præsumptione, levitate aut impatientia recedere quæruntur. Unde Sapiens : Sicut avis, inquit, transmigrans de nido suo, sic vir qui relinquit locum suum. _Sed consolantes_ collectionem, id est fratres nostros, animando eos ad patientiam et inseparabilem unionem. _Et tanto magis hoc facite, quanto amplius videritis oculo cordis appropinquantem diem_ mortis atque judicii particularis. Qui dies quia quotidie appropinquat, debemus quotidie magis ac magis invite collectionem nostram desererere. Scriptum est enim : Ecce quam bonum et quam jucundum habitare fratres in unum.

Hæc ergo bona agenda et mala vitanda
⟦v. 26⟧ sunt. _Voluntarie enim,_ id est ex habitu, electione, certa malitia seu deliberatione, _peccantibus nobis post acceptam notitiam veritatis,_ id est post cognitionem christianæ doctrinæ, in qua pœnæ impiorum gaudiaque justorum describuntur, _jam non relinquitur pro peccatis hostia,_ id est, talibus non restat sacrificium pro peccatis eorum immolandum aliud a sacrificio seu hostia quam pro nobis obtulit Christus. Quod ostenditur per locum a minori :

_Irritam enim,_ id est vacuam, _quis faciens,_ id est transgrediens quis, _legem Moysis, sine ulla miseratione judicis, duobus vel tribus testibus moritur,_ id est, ad testimonium tot testium occiditur, secundum legis præceptum : si tamen peccati magnitudo id exigat. _Quanto magis putatis deteriora,_ id est graviora, mereri supplicia, eum qui Filium Dei conculcaverit, eum inhonorando, ejusque mandata spernendo, _et sanguinem testamenti polutum duxerit,_ id est, sanguinem Christi quo confirmatum est novum testamentum, parvi penderit, et quasi insufficientem putaverit ad auferenda peccata, ob hoc asserens legalia simul cum Evangelio observanda, _in quo sanguine,_ id est cujus effusione, _sanctificatus est,_ id est a vitiis expurgatus et gratia decoratus, primum in Baptismo, deinde in Pœnitentia, _et spiritui gratiæ contumeliam fecerit,_ id est, gratiam Spiritus Sancti contempserit, seu Spiritum Sanctum, omnis gratiæ collatorem, a se repulerit, ejusque effectum, videlicet peccatorum remissionem, non ei, sed observantiis legis adscripserit? Talis graviter punietur.

⟦v. 30⟧ _Scimus enim qui dixit,_ id est, veracem esse cognoscimus Deum, qui ait : _Mihi reservate vindictam,_ id est, mihi vel vicariis meis, puta judicibus, _et ego retribuam_ justam ultionem per me vel meos
