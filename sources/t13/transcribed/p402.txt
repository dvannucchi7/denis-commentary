⟦3⟧ _Exhortatio enim nostra_, id est prædicatio qua admonuimus vos, processit _non de errore_, id est ex interiori falsitate aut infidelitate, sicut exhortatio hæreticorum, _neque de immunditia_, id est ex lascivo affectu aut prava intentione ; _neque in dolo_ vobis proposita est : quia ut beatus ⟦Job xiii. 7.⟧ _Job loquitur_, non indiget Deus nostro mendacio, ut pro illo dolos loquamur. _Sed_ ⟦4⟧ _sicut probati_, id est approbati vel electi, _sumus a Deo, ut crederetur nobis Evangelium_, id est, prædicatio evangelicæ legis nobis committeretur, _ita loquimur_, sicut divinitus instituti sumus, _non quasi hominibus placentes_, id est finaliter placere quærentes, quoniam Deus dissipavit ossa eorum qui hominibus placent, _sed Deo qui probat_, id est; per prospera et adversa examinat, tentat et approbat, _corda nostra_, aliisque probata ostendit : jux- ⟦Sap. iii, 6.⟧ ta illud Sapientiæ, _Tanquam aurum in fornace probavit electos Dominus, et quasi holocausti hostiam accepit illos._
⟦5⟧ _Neque enim aliquando fuimus in sermone adulationis_, id est, nunquam vobis adulanter locuti sumus, _sicut scitis_. Unde ⟦Prov. xxiv, 26.⟧ in Proverbiis Salomon docet : Non lactes quemquam labiis tuis ; et Psalmographus, ⟦Ps. cxl, 5.⟧ Oleum peccatoris non impinguet caput meum. _Neque in occasione avaritiæ_, id est, temporale commodum nec directe nec indirecte quæsivimus. _Deus testis est_, qui ⟦Jer. xxix, 23.⟧ apud Jeremiam dicit : Ego sum judex et testis. _Nec quærentes ab hominibus gloriam_, id est laudem, famæ clarificationem, aut venerationem, videlicet _neque a vobis, neque ab aliis : quum_, id est licet, _possemus vobis oneri esse_, id est debitam, imo et magnam venerationem a vobis exigere, _ut Christi apostoli_, id est in quantum summi Sacerdotis vicarii : non tamen referendo honorem ad nos, sed ad Christum finaliter.
