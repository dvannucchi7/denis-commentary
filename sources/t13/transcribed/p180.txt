⟦34⟧ sensu de mulieribus subditur : _Et mulier innupta_, id est vidua, _et virgo, cogitat quæ Domini sunt_, id est, divina præcepta revolvit, in lege Domini meditatur, et divina recogitat, _ut sit sancta_, id est impolluta, munda, et virtutibus perornata, _corpore et spiritu_, id est anima, quatenus nec corporalia nec spiritualia habeat vitia, sed utrumque divinis obsequiis mancipet. _Quæ autem nupta est, cogitat ea quæ sunt mundi, quomodo placeat viro._ Unde et ipsa divisa est, sicut maritus, quoniam nullus eorum toto corde inten⟦Luc. x, 42.⟧ tus est illi uni quod solum necessarium est. Si tamen nihil divinæ dilectioni præponant, vivunt in statu salutis, nec sunt simpliciter a Deo divisi, ut illi qui mortali vitio dividuntur a Deo, de quibus ⟦Osee x, 2.⟧ ait per Osee : _Divisum est cor eorum, nunc interibunt._
⟦35⟧ _Porro hoc, puta non nubere, ad utilitatem vestram dico_, id est, ad majorem profectum vestrum consulo ; _non ut laqueum_, id est fornicationis occasionem, _vobis injiciam_, id est proponam. Si enim Apostolus juberet non nubere, daret imperfectis ad vitia carnis proclivibus, occasionem fornicandi. _Sed dico et consulo hoc ad id_, id est propter id, _quod honestum est_, scilicet ad continentiam observandam, _et quod facultatem præbeat_, id est, hominem aptet, _sine impedimento_, id est sine distractione et molesta sollicitudine, _Domino obsecrandi_, id est Deum per sacra invocandi. Casta enim vita, efficit hominem aptum ad obsecrandum Dominum mente pura et stabili.

Insuper, agit Apostolus de custodibus virginum, quia in primitiva Ecclesia erant patres carnales, et etiam spirituales, ut episcopi, quorum custodiæ virgines committebantur. _Si quis autem custos virgi_⟦36⟧ _num turpem se videri existimat_, id est, hoc putat quod ipse aliis turpis videtur, seu male gratiosus, et inhoneste se habens ; vel, _Turpem se videri existimat_, id est, intra se turpem suspicionem habet ; _super virgine sua_, id est de virgine suæ custodiæ deputata, _quod sit superadulta_, id est, idcirco quod virgo jam attigerit annos pubertatis seu nubiles, appareantque in ea probabilia signa quod nubere cupiat, _et ita oportet fieri_, utpote ut virgo contrahat, eo quod continere non vult ; _quod vult virgo_, faciat custos ejus, tradens eam marito ; _non peccat custos, si nubat virgo._ _Nam qui statuit in corde suo firmus_, id est, custos virginis, qui stabili proposito mentis ordinavit virginem suam in virginitate servare, _non habens necessitatem_ tradendi eam viro, eo quod velit continere, _potestatem autem habens suæ voluntatis_, id est de secura custodia virginis, ita quod potest voluntatem suam implere, per hoc quod virgo sibi consentit, _et hoc judicavit in corde suo_, id est, ex judicio rationis dictavit, _servare virginem suam_ quam custodit, in virginitate, _bene facit. Igitur et qui matrimonio jungit_, id est, marito legitimo tradit, _virginem suam, bene facit._ Facit enim rem licitam. _Et qui non jungit virginem viro vinculo matrimoniali, melius facit._ Magis enim meritorium est, virginem in virginitate servare, quam maritare, ceteris paribus : quia ad majus bonum cooperatur virgini, qui servat eam in virginitate, quam qui copulat eam viro.
