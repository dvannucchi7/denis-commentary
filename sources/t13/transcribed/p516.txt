Et ⟦v. 10⟧ rationabiliter ita confidimus : _Non enim ⟦Sap. xii, 16.⟧ injustus est Deus_, cujus virtus justitiæ initium est, _ut obliviscatur operis vestri_, id est, per modum obliviscentis se habeat, non attendendo nec remunerando vestra opera bona, _et dilectionis Dei ac proximi, quam intus latentem, ostendistis_ foris per actus caritativos (nam exhibitio operis, probatio est caritatis : ideo dicit quoque Salvator, _Si quis diligit me, sermones meos servabit_), _in nomine ipsius_, id est propter amorem Dei et gloriam ejus ; _quia ministrastis_, id est, necessaria vitæ præbuistis et obsequia congrua impendistis, _sanctis_, id est fide et opere christianis,

et ministratis eis, perseverando in opere inchoato : sicut et ad Galatas jam dictum est : _Per caritatem servite invicem._ ⟦Galat. v.13⟧
_Cupimus autem_, zelo vestræ salutis accensi, _unumquemque vestrum eamdem ostentare sollicitudinem_, id est præmemoratam sollicitam ministrationem frequenter ostendere, _ad expletionem spei_, id est ad adipiscendum bonum æternum, præmiumque cœleste speratum, videlicet propter consecutionem verae felicitatis, quæ est expletio, id est actuatio, spei : ostendare, inquam, usque in finem vitæ præsentis. Qui enim perseveraverit usque in finem, salvus erit. _Ut non segnes_, id est pigri ac tepidi, _efficiamini_ : prout in Apocalypsi cuidam improperatur, _Habeo adversum te quod caritatem tuam primam reliquisti_ ; et in eodem libro, _Utinam frigidus esses aut calidus_ ; _verum_, id est sed, _imitatores eorum efficiamini, qui fide et patientia_, id est merito seu actibus fidei atque patientiæ, _hereditabunt promissiones_, id est, promissa cœlestia hereditarie possidebunt, quæ nec oculus vidit, nec auris audivit, nec cor capere valet. ⟦Apoc. ii, 4.⟧ ⟦Ibid. iii, 15.⟧ ⟦1 Cor. ii, 9.⟧ ⟦v. 11⟧ ⟦v. 12⟧
Quod autem factæ sint hominibus promissiones divinæ, consequenter ostenditur. _Abrahæ namque promittens Deus_ bona terrena atque cœlestia, scilicet possessionem terræ Chanaan dandam semini suo, et omnes gentes benedicendas esse in semine suo, videlicet benedictione salutis æternæ, _quoniam neminem_, id est nullum, _habuit per quem juraret, majorem_ : nil enim majus seu dignius est Deo, per quod possit Deus jurare ; _juravit per semetipsum, dicens : Nisi benedicens benedicam te_, id est, in spiritualibus ac temporalibus bonis copiam tibi præstabo : quod si non fecero, non mihi credatur, nec æstimer Deus ; _et multiplicans multiplicabo te_, id est, multos ex te filios procreabo. De hoc legitur in Genesi, quemadmodum Deus juraverat Abrahæ, quod semen ejus esset sicut stellæ cœli, et sicut arena maris. _Et sic Abraham longanimiter ferens_, id est diu patienter exspectans, ⟦Gen. xii, 1-3; xv, 7, 18-21; etc.⟧ ⟦v. 13⟧ ⟦v. 14⟧ ⟦Ibid. xxii, 16, 17.⟧ ⟦v. 15⟧
