### ELUCIDATIO CAPITULI QUINTI : SCIMUS ENIM QUONIAM SI TERRESTRIS DOMUS NOSTRA HUJUS HABITATIONIS DISSOLVATUR.

⟦II Cor. iv, 17.⟧ DIXIT Apostolus in fine præcedentis capituli, quod levis ac momentanea tribulatio præsentis exsilii, æternum gloriæ pondus operetur in nobis. Hujus autem nunc assignat rationem. _Scimus enim_ per revelationem divinam, _quoniam si terrestris domus nostra,_ id est, quod si caro nostra mortalis, _hujus habitationis,_ id est præsentis mansionis, qua anima degit ac hospitatur in corpore, _dissolvatur_ per mortem, vel pro Christo occidatur, _quod ædificationem,_ id est habitaculum, _ex Deo,_ id est a divina virtute, _habemus_ in spe, et habebimus tandem in re, vi-

delicet domum non manufactam, id est carnem impassibilem, glorificatam, non humana potentia, sed divina, æternam in cœlis, id est in cœlo perpetuo duraturam, vel ab æterno prædestinatam. Sed quoniam hanc domum non habebimus ante diem judicii, Apostolus loqui videtur de eo quod statim post dissolutionem corporis, animæ perfectorum consequuntur. Ideo, alii per domum istam non manufactam, intelligunt gloriam animæ, quæ dicitur domus, propter excellentiam suam ad animæ capacitatem. ⟦v. 12⟧ _Non iterum commendamus nos vobis,_ id est, ad propriam laudem ista non dicimus, sicut nec ante; _sed occasionem,_ id est causam incidentalem atque materiam, _damus vobis_ per commemorationem istorum, _gloriandi,_ id est spiritualiter exsultandi, _pro nobis,_ id est pro gratia nobis concessa, vel pro defensione nostra contra æmulos et detractores nostros, qui conantur se nobis præferre, et vos a nobis avertere; _ut habeatis_ rationabilem responsionem et veram lætitiam _ad eos qui in facie,_ id est de apparente et simulata justitia, _gloriantur, et non in corde,_ id est non ex conscientiæ puritate, neque de veris virtutibus. Quod autem non commendemus

nos ipsos inaniter, et quod vos pro nobis gloriari possitis, patet ex hoc: 
⟦v. 13⟧ _Sive enim mente excedimus,_ contemplando divina, et supergrediendo terrena; _Deo,_ id est, hoc gratiæ Dei adscribimus, atque ad gloriam ejus referimus. _Sive sobrii sumus,_ instruendo vos in moralibus, et condescendendo infirmitatibus vestris; _vobis,_ id est, ad vestram utilitatem hoc facimus. Vel sic: Sive mente excedimus, id est, laudando nos ipsos insensati esse videamur (quia stultorum est, laudibus B propriis inhærere); Deo, id est, ad gloriam Dei hoc agimus, ut benedicatur Deus in donis suis. Sive sobrii sumus, moderate loquendo de perfectionibus nostris, sicut ad virtuosum sapientemque pertinet, ut in his quæ propriam laudem concernunt, magis declinet ad minus quam ad majus; vobis, id est, pro vestri informatione et commodo hoc facimus.
⟦v. 14⟧ _Caritas enim Christi,_ id est dilectio qua Christum proximumque diligimus, _urget,_ id est, incitat et vehementer inclinat, nos ista efficere, quoniam Christi gloriam et proximorum salutem tanto amplius zelamus, quanto in vera caritate perfectiores fuerimus; _æstimantes,_ id est firmiter reputantes, _hoc, quoniam si_ (pro quia) _unus,_ utpote solus Christus, _pro omnibus hominibus liberandis mortuus est, ergo omnes mortui sunt,_ id est vitiis mortificati merito passionis Christi, quantum est ex parte ipsius Salvatoris, qui moriendo omnia ad se traxit. Vel, Omnes mortui sunt, id est, mortem culpæ incurrerunt ex originali peccato: aliter non egerent salvatore. _Et pro omnibus mortuus est Christus, ut et qui vivunt_ vita naturæ seu gratiæ, _jam non sibi vivant,_ id est, non propriæ voluntati deserviant, videlicet ad honorem proprium vitam suam ordinent; _sed ei vivant,_ id est, ad ejus honorem et gloriam omnia opera sua interiora exterioraque referant, _qui pro ipsis mortuus est et resurrexit,_ videlicet Christi. Sic vivere Christo, est vere abnegare atque vivifice mortificare se ipsum.

reconciliavit sibi_, id est, peccata nostra nobis ignovit, _per Christum_, id est incarnatione, passione seu merito Christi hominis : imo Christus ut Deus, reconciliavit nos sibi per se ipsum, ut hominem tollem; _et dedit nobis ministerium reconciliationis_, id est, officium evangelicæ

Quoniam quidem Deus_ Pater, vel 19 _Verbum increatum_, imo et Spiritus Sanctus, hoc est Deus Trinitas, _erat in Christo_ homine _mundum_, id est electos, _reconcilians sibi_ (ut dictum est), _non reputans_, id est non juste ulciscens, nec in æternum reservans, _illis delicta ipsorum_ originalia aut actualia. Christus namque Agnus Joann.i,29. Dei omnia tulit peccata. _Et posuit in nobis verbum reconciliationis_, id est prædicationem pacificationis inter Deum et homines factæ.

20 _Pro Christo ergo_, id est pro Christi amore et gloria, _legatione_, id est missione, _fungimur_, quia a Deo missi sumus 1 Cor.i,17. annuntiare Evangelium Christi, _tanquam Deo exhortante corda audientium per nos_, id est per prædicationem nostram. Ipse enim loquitur per nos. _Obsecramus pro Christo_, id est vice, loco, vel amore Christi, _reconciliamini Deo_, id est, peccata vestra deflete, vitam corrigite, Deo placere contendite. _Eum qui non noverat_ 21 _peccatum_ per approbationem vel experientiam, scilicet Christum, _Pater pro nobis_, id est pro nostra redemptione, _peccatum fecit_, id est hostiam pro peccato. Sumitur enim hic peccatum pro hostia peccati, sicut et apud Osee, ubi dicitur : _Peccata populi mei comedent._ Vel sic : Osee iv, 8. _Eum qui non noverat peccatum, pro nobis peccatum_, id est culpam, fecit. Peccatum enim, præcipue originale, occasio fuit incarnationis passionisque Christi, sicque quodam modo fecit eum hominem. _Ut nos efficeremur justitia Dei_, id est justificati a Deo, _in illo_, id est merito Christi.
