Deinde ostendit Apostolus, quid figurabatur per hoc quod summus sacerdos seu pontifex in lege, introivit in Sancta sanctorum cum sanguine, semel in anno, ad deprecandum pro se et pro aliis. Per pontificem enim figuratus est Christus ; per Sancta sanctorum, cœlum. _Christus_ ⟦11⟧ _autem adsistens_ Deo Patri ad interpellandum pro nobis, _adsistens quoque seu_ ⟦Rom. viii. 24; Hebr. vii, 25.⟧ paratus succurrere nobis, _pontifex,_ id est summus ac sacerdotalis minister, prout homo ; vel, Pontifex, id est suo pontificatu collator ; _futurorum,_ id est cœlestium, _bonorum_ : de quibus legitur in Psalmo, Credo videre bona Domini in terra ⟦Ps.xxvi,13.⟧ viventium ; _per amplius,_ id est multo majus atque capacius, _et perfectius tabernaculum,_ utputa cœlum, _non manufactum,_ id est non hominum manibus fabricatum, _id est non hujus creationis,_ hoc est non humanæ industriæ ; vel, Non hujus creationis, id est non exsistens de natura inferiorum creaturarum, quæ corruptibiles sunt : illud enim incorruptibile est ; ⟦12⟧ _neque per sanguinem hircorum aut vitulorum,_ ut pontifex legalis ; _sed per proprium sanguinem,_ id est cum prævia proprii sanguinis effusione, _introivit semel,_ videlicet in die ascensionis, _in Sancta,_ id est in cœleste tabernaculum præfiguratum per Sancta sanctorum, _æterna redemptione inventa,_ id est vera beatitudine nobis recuperata, atque a nobis comperta.

Quod autem testamentum novum confirmatum sit per Christi passionem, probat Apostolus primo per consuetudinem hu⟦16⟧ manam. Ubi enim testamentum est, mors necesse est intercedat testatoris, id est, ad valorem ac robur testamenti hominis requiritur, ut mors testatoris intervenial seu mediet inter testamenti dispositionem et ⟦17⟧ ejus confirmationem. _Testamentum enim_ […]

_in mortuis_, id est per mortem testatorum, _confirmatum est_: _alioquin nondum valet_, id est, nondum efficaciam habet testamentum, _dum vivit qui testatus est_, id est, qui testamentum condidit. Hoc ita est secundum leges civiles atque canonicas. Nam ante mortem potest mutari, quum sit ultima voluntas testatoris. Simili modo novum testamentum, quod est promissio vitæ æternæ evangelicaque doctrina, in morte Christi firmatum est. Unde in cruce dicebat: _Consummatum est._ In as- ⟦Joann. xix, 30.⟧ sertionem enim promissionis ac doctrinæ suæ mori voluit Christus.

Hostia vero quam obtulit Christus, ob suæ dignitatis efficaciam sufficientissima est omnium auferre peccata : ideo non oportet eam reiterari, seu Christum denuo pati. _Alioqui,_ id est, si ita non esset, sed ⟦26⟧ oporteret eam iterari, sequitur quod _oportebat eum,_ videlicet Christum, _frequenter pati ab origine mundi_ usque in præsens, imo et usque in finem sæculi hujus.
