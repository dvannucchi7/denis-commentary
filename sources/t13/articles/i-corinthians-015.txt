ARTICULUS XV

### EXPOSITIO CAPITULI QUINTIDECIMI : NOTUM AUTEM VOBIS FACIO, FRATRES, EVANGELIUM.

COMPLETO tractatu de sacramentis et
gratis, nunc agit de resurrectione
mortuorum : de qua primo recte instructi fuerunt Corinthii ab ipso Apostolo :
postmodum vero quum recessisset Apostolus, a perversis infecta est fides illorum
⟦1⟧ de resurrectione futura. Itaque ait : _Notum_
_autem vobis facio, fratres,_ id est,
ad memoriam revoco, clarumque expono,

quiescere nostris statutis. _An in vos solos_
_pervenit?_ id est, non vobis tantum, sed
aliis multis annuntiata et infusa est Christi doctrina. Ideo conformetis vos aliis,
et implete quod dico. _Si quis videtur_ ⟦37⟧
_propheta esse, aut spiritualis,_ id est, qui
vere prophetat, exponendo Scripturarum
mysteria, vel prædicendo futura, _cognoscat,_ id est, spiritualiter pensет, _quæ scribo vobis, quoniam Domini sunt mandata,_
id est ex divina inspiratione a me prolata, non ex proprio corde conficta. _Si_ ⟦38⟧
_quis autem ignorat_ ista quæ scire tenetur, _ignorabitur,_ id est, a Deo non cognoscetur notitia approbationis : sicut
nec illi quibus dicitur, _Nescio vos unde_ ⟦Luc. xiii. 25.⟧
_sitis._

_Itaque, fratres, æmulamini,_ id est desiderate, _prophetare_ (secundum sensum jam sæpe præhabitum); _et loqui linguis,_ id est uti dono linguarum, _nolite prohibere_ _eos qui possunt sic loqui,_ quamvis melius sit prophetare. _Omnia autem_ ⟦40⟧ _quæ fiunt inter vos, honeste,_ id est virtuose, _et_ _secundum ordinem,_ id est ordinate, _fiant in vobis,_ ut nihil reprehensibile in actibus vestris appareat, et cum debitis circumstantiis cuncta agantur. Optimum enim in rebus est ordo; et peccatum non est nisi recessus ab ordine.
