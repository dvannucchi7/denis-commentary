_Sive spiritus_, id est ventus, _sibilans, aut inter spissos arborum ramos avium sonus suavis, aut vis aquæ decurrentis nimium_, id est sonus causatus ex cursu aquarum, _aut sonus validus præcipitatarum petrarum_, id est lapidum a sursum projectorum deorsum, _aut ludentium animalium cursus invisus_, id est factus extra intuitum Ægyptiorum illorum, _aut mugientium valida bestiarum vox, aut resonans de altissimis montibus echo_, utpote ex repercussione reflexus; _deficientes faciebant illos præ timore_, id est, debilitabant Ægyptios, qui ex prædominante timore jugiter suspicabantur sibi grandia imminere pericula.
_Omnis enim orbis terrarum_, id est totus 19
mundus, _limpido illuminabatur lumine_, id est claro lumine solis, _et non impeditis operibus continebatur_ : id est, proprios actus expedite naturaliterque exercuit, dempto territorio Ægyptiorum. Unde subjungitur : _Solis autem illis superposita erat_ 20 _gravis nox_, durans per triduum. Alibi vero dies et nox consueto cursu fiebant. _Imago tenebrarum, quæ superventura illis erat_ : id est, nox illa fuit figura, imago et signum infernalium tenebrarum : in quas erant descensuri post vitam hanc, quia non fuerunt conversi, saltem pro parte majori. _Ipsi ergo sibi erant graviores tenebræ_ : id est, propria incredulitate ac obstinatione plus obtenebraverunt se intus, quam forinsecus obscurabantur; suisque sceleribus fuerunt sibi causa quod corruerunt in tenebras infernales, temporalibus illis tenebris graviores.
